# Wallpapers

My collection, sorted into folders. `install.sh` copies them to
`~/Pictures/Wallpapers`; the desktop widgets in `dynamic-island/scenes.json`
are tied to exactly these folder and file names.

| Folder | Content |
| --- | --- |
| `Cyberpunk-Edgerunners/` | Cyberpunk: Edgerunners |
| `Lord-of-the-Mysteries/` | Lord of the Mysteries |
| `Miku/` | Hatsune Miku |
| `Rimuru/` | That Time I Got Reincarnated as a Slime |
| `Graphite/`, `Oxocarbon/`, `Rosepine/`, `Slatemist/` | matching the color schemes of the same name |
| `Tactical/` | dark HUD look |
| `Wallhaven/` | downloaded via the Wallhaven search (`SUPER + ALT + W`) |

The images are not mine. They belong to their respective artists or rights
holders and mostly come from [wallhaven.cc](https://wallhaven.cc). If you
made one of these images and don't want it here, open an issue and it will be
removed.
